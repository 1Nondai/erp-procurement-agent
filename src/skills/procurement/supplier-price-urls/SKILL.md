# 物料询价站点映射

## 用途

提供「物料名称 → 询价站点 → 报价页面 URL」的映射查询，是外部数据采集的第一步。

与旧版按"零件+供应商"逐条维护不同，现在的口径是**按物料映射到对应询价站点**：
一个物料条目指向一个行业的公开报价/行情页面，页面上的价格是市场参考价，
用于和 ERP 里 `material_price_compare` 拿到的供应商报价做交叉验证。

## 数据文件

映射数据在 `data/url_mapping.yaml`。

```yaml
mappings:
  - part_name: "物料名称（含规格、品牌等描述，与 material_query 的 name+spec 对齐）"
    supplier: "询价站点或商家名称（公开 B2B 平台写平台名，表示多供应商）"
    url: "询价/报价页面URL（真实可访问）"
```

> URL 指向的页面包含产品与行情信息：价格、规格、单位、品牌、材质等。
> 爬虫技能可一次性提取全部数据，无需多次请求。
> 字段名 `part_name` 是历史命名，语义已统一为**物料名称**，不要理解成"零件"。

## 站点覆盖（按物料分类）

| 分类 | 映射站点 |
|------|----------|
| 台面 / 板材 | 1688 平台（理化板、环氧树脂板、三聚氰胺板等搜索页） |
| 钢材 | 找钢网、我的钢铁网 |
| 五金 | 五金网、1688 平台 |
| 玻璃 | 中国玻璃网 |
| 水暖 | 水暖配件网、1688 平台 |
| 电气 | 中国工控网（产品页） |
| 通风 | 1688 平台 |
| 涂装 | 中国化工网（行情页） |
| 辅材 | 1688 平台 |

## 使用流程

1. 用 `material_query` 拿到物料名与规格（如 `理化板台面` / `1220×2440×13mm 威盛亚`）
2. 用 `read_file` 读取 `data/url_mapping.yaml`
3. 解析 YAML，按物料名做包含匹配（ERP 返回的物料名包含在映射的 `part_name` 中，或反之）
4. 命中后把 URL 列表传给爬虫技能（`web-scraper`）获取市场报价与产品详情
5. 多条命中时可全部抓取，取最近/最相关的作为外部参考价

## 示例

```python
material_query(name="理化板台面") → 命中 MAT-0001 理化板台面 1220×2440×13mm 威盛亚
→ 读 url_mapping.yaml
→ part_name 包含 "理化板台面"
  → supplier="1688 平台（多供应商）"
    url="https://s.1688.com/selloffer/offer_search.htm?keywords=..."
→ 传给 web-scraper 爬取该 URL → 获取市场价 + 规格 + 单位
→ 与 material_price_compare(material_id=1) 的供应商报价并列呈现
```

## 注意事项

- 映射表由运维人员维护，Agent 只读不写
- `url` 必须是真实存在、可访问的站点地址；**禁止填写占位域名、演示地址或内网 IP**
- 未找到匹配条目 → 改用 `web_search` 搜索该物料的市场价格
- 外部站点价格是**市场参考价**，不等于公司的采购成交价；报告里必须分开标注来源
- 抓取失败（403/超时/反爬）→ 换 `web_search` 或换该分类下的另一个站点，不要重复轰炸同一 URL
- 同一物料可能有多个站点条目，全部收集后交给爬虫逐一抓取
